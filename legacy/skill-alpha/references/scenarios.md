# 首版场景与提问重点

以下是拟开发范围，具体法律解释仍须对应规则通过专业审核。

| 领域 | 场景 | 先核对的事实 |
| --- | --- | --- |
| 自然人借贷 | 没借条 | 钱是否实际交付；当时如何约定钱的性质 |
| 自然人借贷 | 约定期限后不还 | 约定日期、付款及催收记录 |
| 自然人借贷 | 没说清还款日 | 是否有后续约定或催告，相关日期 |
| 自然人借贷 | 利息或借款与投资争议 | 当时的文字约定、实际履行、收益与风险安排 |
| 住房租赁 | 押金不退 | 合同押金条款、退房交接及损失证据 |
| 住房租赁 | 提前退租 | 期限、解除条款、通知与交接日期 |
| 住房租赁 | 房屋维修 | 故障状况、维修约定、通知和处理经过 |
| 住房租赁 | 搬离或转租争议 | 合同转租及解除条款、通知、实际占有情况 |
| 婚姻财产 | 婚前与婚后房产 | 购买、登记、结婚及付款时间 |
| 婚姻财产 | 工资与存款 | 取得时间、来源和财产约定 |
| 婚姻财产 | 首付与还贷来源 | 资金来源、还款记录、登记及约定 |
| 婚姻财产 | 离婚财产约定及登记 | 协议内容、登记机关收到申请的时间与过程 |

首轮通常简短、用生活语言，先解答主要疑问，再问一两项会改变判断的事实。不要把转账直接等同借款成立，不直接按银行卡归属判定财产权属，不自动推算分房比例。用户纠正前提时更新事实状态。
